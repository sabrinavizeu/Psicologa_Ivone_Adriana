## 📖 Sobre o projeto

Landing page de apresentação profissional, com perfil, formação acadêmica,
experiência de trabalho, explicação sobre a abordagem terapêutica (Terapia
Cognitivo-Comportamental) e botão de contato direto via WhatsApp.

O projeto foi desenvolvido para uso real, mas não seguiu para produção
porque a cliente optou por contratar um serviço que já inclui hospedagem e
criação de site. O design e a implementação ficaram completos e
funcionais, então decidi manter o projeto como peça de portfólio.

## ✨ Destaques técnicos

- Layout em grid, responsivo (sidebar + conteúdo principal)
- Animação de entrada dos cards ao rolar a página (scroll reveal, JS puro)
- Efeitos de hover e sombras em camadas pra dar profundidade visual
- Sem frameworks — HTML, CSS e JavaScript puros

## 🛠️ Tecnologias

- HTML5
- CSS3 (Grid, gradientes, animações)
- JavaScript (vanilla)

## ▶️ Como ver

Abra o arquivo `index.html` direto no navegador, ou acesse a versão
publicada (depois de ativado o GitHub Pages neste repositório).
